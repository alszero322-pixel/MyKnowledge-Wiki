## フォームファクタ
光トランシーバの形状の規格のことである。
使用するフォームファクタによって速度や使用するPMD規格などが異なる。
| フォームファクタ | 速度 |
| SFP | 1Gbps |
| SFP+ | 10Gbps |
| SFP28 | 25Gbps |
| QSFP+ | 40Gbps |
| QSFP28 | 100Gbps|

## PMD規格
IEEE 802.3によって標準化されている繋がるかを決める規格である。
- SR(Short Reach): 短距離マルチモード
- LR(Long Reach): 長距離シングルモード
両端のPMD規格が対応していないとリンクアップしないためSRとLRは成立しない。

## 光ファイバの種類
- MMF
コア系: 50㎛前後
光源: LED/VCSEL
距離: 数百メートルまで
用途: 同一ビル内など
- SMF
コア系: 9㎛前後
光源: レーザーダイオード
距離: 数十キロ以上
用途: 拠点間など
