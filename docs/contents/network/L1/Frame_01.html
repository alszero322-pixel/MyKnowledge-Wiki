ラック内接続

DACとAOC

ラック内接続では、トランシーバ+別ケーブルよりも一体型のほうが消費電力と遅延が小さい。

DAC

DAC(Direct Attach Copper)とは、両端のモジュールと銅線が一体になったものである。 コストは安いが距離は数メートル程度。

AOC

AOC(Active Optical Cable)とは、両端のモジュールと光ファイバが一体になったものである。 コストはDACより高いが100メートル程度まで距離がある。
