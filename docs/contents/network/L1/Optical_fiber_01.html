光ファイバ

フォームファクタ

光トランシーバの形状の規格のことである。 使用するフォームファクタによって速度や使用するPMD規格などが異なる。

| フォームファクタ | 速度 | | SFP | 1Gbps | | SFP+ | 10Gbps | | SFP28 | 25Gbps | | QSFP+ | 40Gbps | | QSFP28 | 100Gbps|

PMD規格

IEEE 802.3によって標準化されてい る繋がるかを決める規格である。

  • SR(Short Reach): 短距離マルチモード]
  • LR(Long Reach): 長距離シングルモード

光ファイバの種類

MMF

コア径: 50㎛前後
光源: LED/VCSEL
距離: 数百メートルまで
用途: 同一ビル内など

SMF

コア径: 9㎛前後
光源: レーザーダイオード
距離: 数十キロ以上
用途: 拠点間など

典型的なカラーコードについて

MMF
  • OM1/OM2: 橙
  • OM3/OM4: 水色
  • OM4: エリカ紫
  • OM5: ライムグリーン
SMF

→ 黄色
