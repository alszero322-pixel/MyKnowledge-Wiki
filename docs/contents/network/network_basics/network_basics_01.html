ネットワークのの基礎

ITにおけるネットワークとは、複数のコンピュータやデバイスがケーブルなどで接続され、相互に通信できる状態のシステムのことである。

ネットワーク基礎用語

ノード

ネットワークを構成する、PCやルータ, プリンタなどのデバイスのこと。

リンク

ノードとノードを結ぶケーブルなどの線のこと。

フロー

リンク上のデータの流れのこと。

トラフィック

ネットワーク上を流れる情報、及びその量のこと。

プロトコル

データをどのような手順、形式で送受信するかを定めた規則のこと。

特にネットワーク上での通信や手順を定めたものは通信プロトコルと呼ばれる。

プロトコルスイート (プロトコルスタック)

複数のプロトコルを階層的に組み合わせて構成されるもの。OSI参照モデルやTCP/IPモデルなどがある。

ベンダー

ネットワークの機器メーカーのこと。

ホスト

ネットワークに接続されているコンピュータのこと。

特にサービスを利用する側はクライアント、提供する側はサーバーと呼ばれる。

セッション

通信が開始してから終了するまでの一つの接続のこと。

エンドツーエンド

通信を開始する送信元から最終的な宛先までの通信のこと。
