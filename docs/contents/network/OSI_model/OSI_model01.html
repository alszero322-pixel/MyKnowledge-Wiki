OSI参照モデル(Open System Interconnection)

ISO/IEC 7498-1及びITU-T X.200で定義されている、ネットワーク通信を7段階に階層化したモデルのことである。

OSI参照モデルは、次の7つの階層から構成される。

  • L7: アプリケーション層
  • L6: プレゼンテーション層
  • L5: セッション層
  • L4: トランスポート層
  • L3: ネットワーク層
  • L2: データリンク層
  • L1: 物理層

OSI参照モデルのメリット

OSI参照モデルのメリットは以下の通りである。

  • 各階層の役割を理解しやすい。
  • 標準化されているため、異なるベンダーやプロトコルの組み合わせが可能になる。
  • 階層ごとの独立性が高い。
  • 責任や問題の切り分けや解決を早い段階で可能になる。

各階層の役割

L7 アプリケーション層

ユーザが利用するアプリケーションソフトウェア間の通信を規定する層。
関連する技術には、HTTP, FTP, SMTP, DNSなどがある。
L7の典型トラブル例: 名前解決の失敗、HTTPのステータスコードが40X,50Xなど

L6 プレゼンテーション層

符号化や文字コードなどのデータの表現方式を規定する層。
関連する技術には、TLS, SSL, JPEG, MPEGなどがある。

L5 セッション層

セッションの確立や終了を規定する層。
関連する技術には、RPC, NetBIOSなどがある。


L6/L5の典型トラブル例: TLSハンドシェイクの失敗、証明書の有効期限やホスト名検証の失敗、受信データの文字コードや圧縮形態の不一致など

L4 トランスポート層

ノード間の通信の制御を規定する層。
関連する技術には、TCP, UDPなどがある。
L4の典型トラブル例: 接続拒否、タイムアウト、応答なしなど

L3 ネットワーク層

エンドツーエンドの通信に関して規定する層。
関連する技術には、IP, ICMPなどがある。
L3の典型トラブル例: 経路なし、経路誤り、ICMP遮断、ブラックホールなど

L2 データリンク層

直接接続されたノード間の通信を規定する層。
関連する技術には、Ethernet, WiFi, PPPなどがある。
L2の典型トラブル例: VLAN不一致、ループ、ポートの保護機能による停止、MAC学習異常など

L1 物理層

物理的な接続や電気信号とデータの変換を規定する層。
関連する技術には、光ファイバ, 同軸ケーブル,などがある。
L1の典型トラブル例: 機器異常、リンクダウン、CRCなど
