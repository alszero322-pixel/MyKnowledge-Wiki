# HTMLについて1

## HTMLは最初にDOCTYOE宣言をする。
```<!DOCTYPE html>```
これは文書型宣言と呼ばれ、ウェブブラウザにページがHTML5で記述されていることを伝える。
→ブラウザが正しくページをレンダリングできる。

### なんで文書型宣言が必要？
昔のブラウザを現在のルールで表示するとレイアウトが崩れてしまうため、文書に応じて動作を切り替える仕組みが必要だから。

### 文書型宣言の種類
- 標準モード(no-quirks mode): HTML/CSSの標準に沿って処理を行う。
- 後方互換モード(quirks moed): 過去の特殊な動作を再現する、古いページのためのモード。
- 限定後方互換モード(limited-quirks mode): 一部の特殊な動作だけを残す。

```<!DOCTYPE html>```を先頭に置くことで、標準モードとして処理を行う。
省略すると後方互換モードとなる。

### 文書型宣言の特徴
- HTMLの要素ではないため、終了タグ(</>)がない。
- HTMLのバージョン番号は表記しない。
- 大文字と小文字は区別されない。

## htmlルートコンテナと言語指定
```<html lang="en"></html>```
<!DOCTYPE>宣言を除いたすべてのHTML要素のルートコンテナを追加する。
このタグ内にlang属性を含めることで内側にある要素にも同じ属性を引き継ぐ(継承)ことがベストプラクティスである。

### なぜ言語指定が必要？
- 人間、機械双方にとって明示的に指定されていると適切に処理がしやすい。
- 特に検索エンジンやスクリーンリーダーによる読み上げにとって重要である。

### 一部分のみの言語指定
``` <html lang="en">```
        <p>This is English.</p>
        <p lang="ja">これは日本語です。</p>
    </html>
上記のように一部分のみの言語指定も可能である。

### BCP 47について
langの値にはBCP 47に従った言語タグを用いる必要がある。
- ja: 日本語
- en: 英語
- en-US: アメリカ英語
- fr: フランス語
- zh-Hans: 簡体字中国語
